# Need-to-know notifications

Routine status changes, checklist completions, and archive/restore/section updates are off by default for both new inbox notifications and pending device pushes. Explicit global and property preferences still override defaults. Routine edits remain in activity history.

Assignments, schedule changes, approaching deadlines, risk alerts, comments, final-walk actions and unit readiness keep their existing delivery rules. Parts-order requests now have a separate MATERIALS_REQUEST category so muting routine status changes does not suppress purchasing requests.

Alerts has a Need-to-know only button. It disables the three routine categories for the current user, removes their per-property overrides, and preserves all important-alert preferences and quiet hours. Existing inbox entries are not deleted or marked read. Users can opt back into individual categories. No database migration is required.
