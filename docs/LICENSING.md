## Hosting And Distribution

If you modify the software and users interact with it over a network,
section 13 requires a prominent offer to those users to receive the
Corresponding Source of your version, at no charge through a standard
means of copying software. An accessible Source Code link in the running
application is one way to provide this offer.

Provide the source matching the version actually running, including your
modifications and the build/install material required by the license.
Linking only to upstream is not sufficient when your deployed version
contains changes that are absent upstream. Keep the matching revision or
source archive available and update the offer when deploying changes.

For distributed copies, preserve the required notices, include the license,
identify modifications, and meet the applicable source-distribution terms.
The full license governs; this guide is not a substitute for its terms or
legal advice about a particular deployment.

Resident data, database dumps, credentials, and private server configuration
are not software source and must not be published as part of a source offer.
Use safe configuration examples rather than production secrets. Modifications
to the application itself still need to be included where required.
